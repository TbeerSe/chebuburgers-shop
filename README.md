# 🍔 ЧебуБургер

Одностраничный лендинг фастфуд-ресторана с корзиной, фильтрами меню и формой заказа. Чистый фронтенд без фреймворков.

**[Демо](https://tbeerse.github.io/chebuburgers-shop/)**

## Что внутри

- Каталог блюд с фильтрацией по категориям
- Корзина с сохранением в `localStorage`
- Изменение количества и удаление позиций
- Валидация формы заказа и маска российского телефона
- Полностью адаптивная вёрстка (mobile-first)
- Доступность: ARIA, клавиатурная навигация, `prefers-reduced-motion`

## Стек

HTML · CSS · JavaScript (ES Modules)
